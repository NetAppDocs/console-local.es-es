= Puertos para el agente de Console on-premises en el despliegue local de NetApp Console
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
En una implementación local de NetApp Console, el agente de Console utiliza puertos _de entrada_ cuando se instala manualmente en un host Linux local. Consulta estos puertos para fines de planificación.

Estas reglas de entrada se aplican a todos los modos de implementación de NetApp Console.

[cols="10,10,80"]
|===
| Protocolo | Puerto | Propósito 


| HTTP | 80  a| 
* Permite el acceso HTTP desde los navegadores web de los clientes a la interfaz de usuario local
* Se utiliza durante el proceso de actualización de Cloud Volumes ONTAP




| HTTPS | 443 | Permite el acceso HTTPS desde los navegadores web de los clientes a la interfaz de usuario local 
|===
