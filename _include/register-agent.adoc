Inicia sesión en la Console y asocia el Console agent con tu organización. Cómo inicies sesión depende del modo en el que estés usando Console. Si estás usando la Console en modo estándar, inicias sesión a través del sitio web SaaS. Si estás usando la Console en modo restringido o privado, inicias sesión localmente desde el host del Console agent.

.Pasos
. Abre un navegador web e introduce la URL del host del agente de Console:
+
La URL del host de la Consola puede ser un localhost, una dirección IP privada o una dirección IP pública, dependiendo de la configuración del host. Por ejemplo, si el agente de la Consola está en la nube pública sin una dirección IP pública, debes introducir una dirección IP privada de un host que tenga conexión con el host del agente de la Consola.

. Regístrate o inicia sesión.
. Después de iniciar sesión, configura la NetApp Console:
+
.. Especifica la organización de NetApp Console que quieres asociar con el agente de NetApp Console.
.. Introduce un nombre para el sistema.
.. En la sección *¿Estás ejecutando en un entorno seguro?* mantén desactivado el modo restringido.
+
El modo restringido no es compatible cuando el agente de Console está instalado en las instalaciones locales.

.. Selecciona *Empecemos*.
